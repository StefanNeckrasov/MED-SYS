# Медицинская информационная система

Приложение для ведения и управления медицинскими записями пациентов с графическим интерфейсом на Tkinter и базой данных SQLite. Позволяет добавлять, просматривать, редактировать, искать и распечатывать карточки пациентов.

## Основные возможности

- **Добавление новых записей** – все основные медицинские данные (ФИО, диагноз, давление, количество сеансов/курсов и др.)
- **Просмотр всех записей** в виде таблицы с краткой информацией
- **Поиск** по любому полю или по конкретному атрибуту с учётом регистра
- **Редактирование** – двойной клик по строке открывает карточку пациента с возможностью изменения данных
- **Печать карточки пациента** – формирование текстового отчёта и отправка на принтер
- **Валидация ввода** – даты, года рождения, возраста, значения давления
- **Автоматическое создание базы данных** при первом запуске

## Технологии

- Python 3.7.9
- Tkinter – графический интерфейс
- SQLite – встроенная база данных
- ttk – современные виджеты

## Установка и запуск

1. Убедитесь, что установлен Python 3.7.9 или выше.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/StefanNeckrasov/MED-SYS.git
   cd MED-SY
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```
   > Никаких дополнительных зависимостей не требуется – все модули входят в стандартную библиотеку Python.

4. При необходимости можно собрать исполняемый файл с помощью PyInstaller или auto-py-to-exe:
   ```bash
   pip install pyinstaller
   pyinstaller --onefile --windowed --add-data "database.py;." --add-data "patient_card.py;." --add-data "validators.py;." main.py
   ```

## Использование

### Главное окно

- **Левая панель** – форма добавления нового пациента. Заполните обязательные поля (ФИО, диагноз, дата лечения) и нажмите «Добавить запись».
- **Правая панель** – таблица со списком всех пациентов. Строки сортируются по убыванию ID (сначала новые).
- **Поиск** – выберите поле для поиска (или «Все поля»), введите текст и нажмите «Найти». «Сбросить» очищает поиск и показывает все записи.
- **Двойной клик** по строке открывает карточку пациента для просмотра и редактирования.
- Кнопка **«Обновить данные»** перезагружает таблицу.

### Карточка пациента

- Отображает все поля выбранной записи.
- **Редактирование** – измените нужные данные и нажмите «Сохранить изменения».
- **Печать** – создаётся текстовый файл во временной папке и отправляется на системный принтер (Windows: `os.startfile(..., "print")`, Linux/macOS: команда `lp`).
- **Отмена** закрывает окно без сохранения.

### Валидация полей

- **Дата лечения** – строго в формате `ДД-ММ-ГГГГ`.
- **Год рождения** – целое число от 1900 до 2100.
- **Возраст** – целое число от 0 до 150.
- **Давление** – положительное число (целое или дробное), обязательно указание единиц (`ата` или `ати`).
- **Количество сеансов/курсов** – неотрицательные целые числа.

## Структура проекта

```
medical-info-system/
├── main.py           # Главный модуль, запуск приложения и основной интерфейс
├── database.py       # Класс Database для работы с SQLite (CRUD операции)
├── patient_card.py   # Окно карточки пациента (просмотр/редактирование/печать)
├── validators.py     # Класс Validators со статическими методами проверки данных
└── medical_records.db # Файл базы данных (создаётся автоматически)
```

## Требования к системе

- Операционная система: Windows, Linux, macOS (тестировалось на Windows)
- Python 3.7.9+

## Примечания

- База данных `medical_records.db` создаётся в той же папке, что и исполняемый файл.
- При сборке в `.exe` через PyInstaller пути к файлам определяются корректно (через `sys.frozen`).
- Печать на Linux/macOS требует наличия команды `lp` (обычно входит в CUPS).
